# 理由で覚える学科

運転免許の学科試験（普通免許の本免）対策の○✕ドリルです。スマホのブラウザで使えます。

答えを覚えるだけでなく、1問ごとに次の解説を表示します。

| 解説 | 内容 |
| --- | --- |
| 正解のルール | 法令・教則に書かれている正しいルール |
| なぜこのルール？ | そのルールが何を防ぐためにあるのか |
| もし逆だったら？ | ルールが逆だったら、どんな事故や混乱が起きるか |
| 数字の意味 | 「5m」「30m」「0.75m」などの数字の考え方（数字が出てくる問題のみ） |
| ひっかけ注意 | 試験でよく入れ替えられるポイント |
| 根拠 | 道路交通法などの条文、教則の項目 |

## 使い方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。GitHub Pages で公開すれば、スマホからURLで開けます。

- **おまかせ10問**：全分野からランダムに10問。1問ごとに解説
- **模擬テスト50問**：本番と同じく、その場では正誤を出さず、最後にまとめて採点と解説。9割（45問）が合格ライン
- **間違えた問題**：前回まちがえた問題だけを出題
- **2026年の新ルール**：最近の法改正に関わる問題
- **分野ごとに解く**：信号、交差点、駐停車など11分野

学習記録は、使っている端末のブラウザ（localStorage）にだけ保存されます。

### GitHub Pages で公開する

1. GitHub のリポジトリで **Settings → Pages** を開く
2. **Source** を「Deploy from a branch」にして、公開したいブランチと `/ (root)` を選ぶ
3. 表示されたURLをスマホで開き、ホーム画面に追加する

## 問題の出典と正確性

問題文はすべてオリジナルです。教習所や市販の問題集の問題文は使っていません（著作権があり、また本免の実際の試験問題は公開されていないため）。

代わりに、学科試験の出題のもとになっている次の公式の文書を根拠にしています。

- 道路交通法、道路交通法施行令、道路交通法施行規則（[e-Gov法令検索](https://laws.e-gov.go.jp/law/335AC0000000105)）
- 交通の方法に関する教則（国家公安委員会告示）（[警察庁](https://www.npa.go.jp/koutsuu/kikaku/kyousoku/index.htm)）
- 自動車の保管場所の確保等に関する法律、自動車損害賠償保障法、道路運送車両法（該当する問題のみ）

正確性のために、次の方針で作っています。

- 「正解のルール」と「根拠」には、法令・教則に書かれていることだけを書く
- 「なぜ」「もし逆だったら」「数字の意味」は理解のための説明であることを画面上に明記する
- 条文番号に確信が持てないものは、番号を書かずに法令名・教則の項目名だけを示す
- 改正されたかどうか確認しきれなかった内容（故障車をけん引するときの最高速度など）は出題しない

### 反映している法改正（2026年9月時点）

- **2026年9月1日施行**：中央線・車両通行帯がなく、中央分離帯などで往復の方向が分けられてもいない一般道路（生活道路）の自動車の法定速度が、時速60kmから30kmになりました（道路交通法施行令第11条）
- **2026年4月1日施行**：自動車が自転車の右側を通過するとき、十分な間隔がなければ、間隔に応じた安全な速度で進行する義務ができました（道路交通法第18条）

古い問題集では答えが違う問題があります。アプリ内では「新ルール」のラベルを付けています。

誤りに気づいたら、問題IDと根拠の条文を添えて Issue で知らせてください。

## 問題を追加・修正する

問題データは `js/data/` に分野ごとに入っています。形式は `js/data/00-categories.js` の先頭のコメントを参照してください。

```sh
npm test            # 問題データの形式チェック（ID重複、必須項目、根拠の有無など）
npm run build:artifact   # 1ファイルにまとめたHTMLを dist/artifact.html に出力
```

外部ライブラリは使っていません（Node.js はチェック用スクリプトにだけ使います）。
